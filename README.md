# Personal Archive

Personal portfolio and archive of projects by Vladyslav Kudriashov. It brings
together backend and frontend work, experiments, and notes about building
software systems and user-facing interfaces.

Live site: [hexlabelposition.dev](https://hexlabelposition.dev)

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Bun

## Getting started

Install the dependencies and start the development server:

```bash
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

```bash
bun dev           # Start the development server
bun run build     # Create a production build
bun start         # Start the production server
bun run lint      # Run ESLint
bun run typecheck # Check TypeScript types
bun run format    # Format the project with Prettier
```
